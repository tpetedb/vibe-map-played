# Obsidian - Graph view

Graph view draws the notes in a vault as circles and the internal links between them as lines, so you can see how notes relate. A local graph shows only the notes connected to the active note.

## Facts

- Open with Open graph view in the Ribbon; the Open local graph command shows notes connected to the active note, with a depth slider
- Circles are notes (nodes) and lines are internal links; the more nodes that reference a node, the bigger it gets
- Zoom with the scroll wheel or the + and - keys, move with the arrow keys, hold Shift to speed up
- Filters: Search files, Tags, Attachments, Existing files only, Orphans
- Groups colour notes that match a search term; Display has Arrows, Text fade threshold, Node size, Link thickness and Animate (a time-lapse by creation time)
- Forces: Center force, Repel force, Link force, Link distance; Restore default settings resets the cog settings

## Try in five minutes

Open graph view from the ribbon, click New group under Groups, enter a search term for a set of notes (for example a tag) and pick a colour, then switch Orphans off and see which notes disappear.
