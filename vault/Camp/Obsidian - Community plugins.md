# Obsidian - Community plugins

Community plugins extend Obsidian with third-party code, installed from a built-in directory after turning off Restricted Mode. They are enabled, updated and uninstalled from Settings > Community plugins.

## Facts

- Settings > Turn on community plugins leaves Restricted Mode; Browse then lists all available plugins
- Install: Settings > Community plugins > Browse, pick a plugin, Install, then Enable
- Plugins do not update automatically: Community plugins > Current plugins > Check for updates, then Update all or Update
- Installed plugins shows Settings, Hotkeys, Funding, Uninstall and a Toggle per plugin, a refresh icon to reload all plugins and a folder icon to open the plugins folder
- Browse in a browser at community.obsidian.md
- Warning: community plugins run third-party code that could do harm; see Plugin security

## Try in five minutes

Open Settings, select Turn on community plugins, click Browse and filter for a plugin you want, Install and Enable it, then open Installed plugins and try its Settings and Hotkeys icons; finish with Check for updates.
