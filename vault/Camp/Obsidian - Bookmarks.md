# Obsidian - Bookmarks

Bookmarks is a core plugin for shortcuts to items you use often: files, folders, graphs, searches, headings, blocks and links, organised into bookmark groups in a sidebar tab.

## Facts

- Bookmarkable items: Files, Folders, Graphs, Searches, Headings, Blocks, Links
- Bookmarks: Show bookmarks opens the tab; Bookmark the active tab sits at the top of it
- Commands: Bookmark, Bookmark heading under cursor, Bookmark block under cursor
- Bookmark a search from the three dots icon next to the number of results; right-click a graph tab to bookmark it (local graphs can't be bookmarked)
- New bookmark group creates a group; drag bookmarks to reorder them or move them between groups
- Bookmark 3 tabs in a tab group's menu bookmarks every tab in the group; Alt or Shift selects multiple files in the File explorer

## Try in five minutes

Open the Bookmarks tab, create a group called Tonight with New bookmark group, bookmark the active note with Bookmark the active tab, then run a search and bookmark it from the three dots menu; drag both into the group.
