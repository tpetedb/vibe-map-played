# Obsidian features

Every feature of Obsidian the help documents, one note each, with the exact commands and a five-minute try. Bootstrap them with `vibe vault feature --all` or one at a time.

## Linking

- [[Obsidian - Internal links]] (done): Internal links point from one note to another note, attachment or file in the vault, in Wikilink or Markdown format.
- [[Obsidian - Embed files]] (done): Embedding shows a file's content inline in a note and keeps it up to date with the source.

## Editing

- [[Obsidian - Tags]] (done): Tags are keywords or topics that help you find notes quickly.
- [[Obsidian - Properties]] (done): Properties store structured data about a note, such as text, links, dates, checkboxes and numbers, as YAML at the top of the file.
- [[Obsidian - Callouts]] (done): Callouts are blockquotes with a type identifier on the first line that render as coloured boxes with an icon, for extra content that does not break the flow of a note.
- [[Obsidian - Hotkeys]] (done): Hotkeys are customisable keyboard shortcuts for Obsidian commands, managed under Settings > Hotkeys, where you add, remove and filter shortcuts and can give one command several combinations..

## Core plugin

- [[Obsidian - Backlinks]] (done): The Backlinks core plugin lists every note that links to the active note, split into Linked mentions and Unlinked mentions, in a sidebar tab or at the bottom of the note itself..
- [[Obsidian - Graph view]] (done): Graph view draws the notes in a vault as circles and the internal links between them as lines, so you can see how notes relate.
- [[Obsidian - Templates]] (done): Templates is a core plugin that inserts pre-defined text from a template folder into the active note at the cursor, replacing variables such as the title, date and time..
- [[Obsidian - Daily notes]] (done): Daily notes is a core plugin that opens today's note or creates it if it does not exist, for journals, to-do lists or daily logs.
- [[Obsidian - Unique note creator]] (done): Unique note creator is a core plugin that creates notes with time-based names, also known as Zettelkasten notes, optionally filled from a template..
- [[Obsidian - Bookmarks]] (done): Bookmarks is a core plugin for shortcuts to items you use often: files, folders, graphs, searches, headings, blocks and links, organised into bookmark groups in a sidebar tab..
- [[Obsidian - Search]] (done): Search is a core plugin that finds text across the vault using search terms, operators, property queries and regular expressions.
- [[Obsidian - Quick switcher]] (done): Quick switcher is a core plugin for finding and opening notes by name or alias from the keyboard, and for creating a note when nothing matches..
- [[Obsidian - Command palette]] (done): The Command palette core plugin runs any Obsidian command from the keyboard with fuzzy matching, shows each command's hotkey, and lets you pin frequently used commands to the top..
- [[Obsidian - Slash commands]] (done): Slash commands is a core plugin that runs commands from inside the editor: type a forward slash at the start of a line or after a space, search the list of commands, and press Enter..
- [[Obsidian - Workspaces]] (done): Workspaces is a core plugin that saves and restores application layouts, including open files and tabs and the width and visibility of each sidebar, so you can switch between setups for journaling, reading or writing..
- [[Obsidian - Outline]] (done): Outline is a core plugin that lists the headings of the active note; click a heading to jump to that section or drag headings to rearrange sections..
- [[Obsidian - Note composer]] (done): Note composer is a core plugin that merges two notes or extracts a selection into another or a new note, updating links as it goes, with an optional template for the new content..
- [[Obsidian - Slides]] (done): Slides is a core plugin that turns any Markdown note into a presentation, with slides separated by a horizontal rule line..
- [[Obsidian - Canvas]] (done): Canvas is a core plugin for visual note-taking: an infinite 2D space where you place text cards, notes, media, folders and web pages, connect them with labelled lines and group them.
- [[Obsidian - Introduction to Bases]] (done): Bases is a core plugin that builds database-like views (table, list, cards, kanban, map) over the notes in a vault, reading data from their properties.
- [[Obsidian - Web viewer]] (done): Web viewer is a desktop core plugin that opens external links in Obsidian tabs, with a reader view, a save-to-vault action and ad blocking, for research without leaving the app..
- [[Obsidian - File recovery]] (done): File recovery is a core plugin that saves complete snapshots of notes at regular intervals so you can restore or copy an earlier version after an accidental deletion or unwanted change.
- [[Obsidian - Page preview]] (done): Page preview is a core plugin that shows a popup preview of a note when you hover over an internal link, without navigating to it..
- [[Obsidian - Random note]] (done): Random note is a core plugin that opens a random note from the vault, to rediscover old notes and link to recently added ones..
- [[Obsidian - Footnotes view]] (done): Footnotes view is a core plugin that lists all footnotes in the active note, lets you edit a footnote's text and jump to its position in the note..

## Format

- [[Obsidian - Obsidian Flavored Markdown]] (done): Obsidian Flavored Markdown combines CommonMark, GitHub Flavored Markdown and LaTeX with Obsidian's own extensions: wikilinks, embeds, block references, footnotes, comments, highlights, callouts and task lists.

## Extending

- [[Obsidian - Obsidian URI]] (done): Obsidian URI is a custom obsidian:// protocol that triggers actions from outside the app, such as opening or creating a note, opening the daily note, a unique note, a search or the vault manager, for automation and cross-app workflows..
- [[Obsidian - Obsidian CLI]] (done): Obsidian CLI controls a running Obsidian app from the terminal, for scripting, automation and agent tooling.
- [[Obsidian - Community plugins]] (done): Community plugins extend Obsidian with third-party code, installed from a built-in directory after turning off Restricted Mode.
- [[Obsidian - CSS snippets]] (done): CSS snippets are small CSS files in the vault's configuration folder that change parts of the Obsidian interface without building a full theme, using Obsidian's CSS variables and the cssclasses property for per-note styling..
- [[Obsidian - Introduction to Obsidian Web Clipper]] (done): Obsidian Web Clipper is a free, open source browser extension that highlights web pages and saves their content to a vault, with templates, variables, filters, logic and an interpreter for natural language prompts..

## Service

- [[Obsidian - Introduction to Obsidian Sync]] (done): Obsidian Sync is a paid add-on service that privately syncs a vault across devices, with selective sync, version history, shared vaults, regional servers and a headless mode..
- [[Obsidian - Introduction to Obsidian Publish]] (done): Obsidian Publish is a cloud hosting service that turns selected notes into a public wiki, knowledge base, documentation site or digital garden, hosted at publish.obsidian.md/your-site..
