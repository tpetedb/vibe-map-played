# Obsidian - Introduction to Obsidian Web Clipper

Obsidian Web Clipper is a free, open source browser extension that highlights web pages and saves their content to a vault, with templates, variables, filters, logic and an interpreter for natural language prompts.

## Facts

- Available from the Chrome Web Store (Chrome, Brave, Arc, Orion and other Chromium browsers), Firefox Add-Ons, Safari Extensions (macOS, iOS, iPadOS) and Edge Add-Ons
- Features: Clip web pages, Highlighter, Reader, Interpreter, Templates, Variables, Filters, Logic
- Saves content locally to your vault; no data is collected and no usage metrics are gathered
- Code is open source at github.com/obsidianmd/obsidian-clipper

## Try in five minutes

Install Web Clipper from your browser's extension store, open an article, highlight one passage with the Highlighter and clip the page into your vault; then open the new note and check the saved content.
