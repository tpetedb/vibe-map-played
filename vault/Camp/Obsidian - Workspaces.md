# Obsidian - Workspaces

Workspaces is a core plugin that saves and restores application layouts, including open files and tabs and the width and visibility of each sidebar, so you can switch between setups for journaling, reading or writing.

## Facts

- A workspace contains the open files and tabs and the width and visibility of each sidebar
- Ribbon icon and Command palette command: Manage workspace layouts
- Save: enter a name and select Save; saving with an existing name updates that workspace
- Load: select Load next to the workspace; Delete: select Delete layout

## Try in five minutes

Arrange two notes side by side with the right sidebar closed, run Manage workspace layouts and save it as Writing; then open the graph and both sidebars, save that as Review, and switch between the two with Load.
