# Obsidian - Slides

Slides is a core plugin that turns any Markdown note into a presentation, with slides separated by a horizontal rule line.

## Facts

- Start with Start presentation from the note tab's right-click menu or the Command palette
- Separate slides with --- at the start of a line surrounded by newlines
- Navigate with the left and right arrow keys or the arrows in the bottom-right corner; Spacebar advances
- Stop with Escape or the cross in the upper-right corner

## Syntax

```
# Presentations using Slides

A demo on how to build presentations using Slides.

---

## Formatting

You can use regular Markdown formatting, like *emphasised* and **bold** text.
```

## Try in five minutes

Write a note with a title, a --- line, and two more sections each separated by ---, then run Start presentation from the Command palette and step through with the arrow keys; press Escape to leave.
