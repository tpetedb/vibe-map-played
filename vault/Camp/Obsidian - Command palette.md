# Obsidian - Command palette

The Command palette core plugin runs any Obsidian command from the keyboard with fuzzy matching, shows each command's hotkey, and lets you pin frequently used commands to the top.

## Facts

- Open with Ctrl+P (Cmd+P on macOS) or the Command palette icon in the Ribbon
- Fuzzy matching: typing scf finds the Save current file command
- As of version 1.8.3, recently used commands appear at the top of the palette
- Pin a command under Settings > Command palette > New pinned command > Select a command
- Unpin under Pinned commands with the cross icon next to the command

## Try in five minutes

Press Ctrl/Cmd+P, type scf and run Save current file, then open Settings > Command palette and pin Open today's daily note as a New pinned command; open the palette again and see it at the top.
