# Obsidian - Backlinks

The Backlinks core plugin lists every note that links to the active note, split into Linked mentions and Unlinked mentions, in a sidebar tab or at the bottom of the note itself.

## Facts

- A backlink for a note is a link from another note to that note
- Two collapsible sections: Linked mentions (notes with an internal link to the active note) and Unlinked mentions (unlinked occurrences of the note's name)
- The Backlinks tab lives in the right sidebar; Backlinks: Show backlinks opens it if hidden
- Backlinks: Open backlinks for the current note opens a linked tab that stays on one note
- Backlinks: Toggle backlinks in document shows them at the bottom of the note; the Backlink in document option does this automatically
- Options: Collapse results, Show more context, Change sort order, Show search filter (uses Search syntax)

## Try in five minutes

Open a note that other notes link to, click the Backlinks tab in the right sidebar and read Linked mentions, then expand Unlinked mentions and find a plain-text mention of the note's name that you can turn into a link.
