# Obsidian - Unique note creator

Unique note creator is a core plugin that creates notes with time-based names, also known as Zettelkasten notes, optionally filled from a template.

## Facts

- A note created at 09:45 on Jan 1st, 2024 is named 202401010945; if that name exists, the next available timestamp is used
- Ribbon: Create new unique note; Command palette (Ctrl+P or Cmd+P): Create new unique note
- Settings > Core plugins > Unique note creator > Template file location sets a template file
- New unique notes are empty by default; the plugin is also known as Zettelkasten prefixer

## Try in five minutes

Enable Unique note creator, press Ctrl/Cmd+P and run Create new unique note twice, compare the two timestamp names, then point Template file location at one of your templates and create a third.
