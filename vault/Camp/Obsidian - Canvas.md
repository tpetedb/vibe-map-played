# Obsidian - Canvas

Canvas is a core plugin for visual note-taking: an infinite 2D space where you place text cards, notes, media, folders and web pages, connect them with labelled lines and group them. Canvases are .canvas files in the open JSON Canvas format.

## Facts

- Create with Canvas: Create new canvas, New canvas in the File explorer context menu, or Create new canvas in the ribbon
- Saved as .canvas files using the open JSON Canvas format
- Double-click the canvas to add a text card; Convert to file... turns it into a note (text-only cards do not appear in Backlinks)
- Add web page embeds a URL; Add note from vault and Add media from vault are in the context menu; dragging a folder adds all its files
- Drag from a card edge to connect two cards; double-click a line to label it; Set color colours cards and connections
- Shift+1 zooms to fit, Shift+2 zooms to selection, Space plus drag pans, Ctrl/Cmd+A selects all, Alt/Option plus drag duplicates

## Try in five minutes

Create a canvas from the ribbon, double-click to add a text card, drag two notes in from the File explorer, connect them with a labelled line, group all three with Create group and press Shift+1 to zoom to fit.
