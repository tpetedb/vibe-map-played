# Obsidian - Slash commands

Slash commands is a core plugin that runs commands from inside the editor: type a forward slash at the start of a line or after a space, search the list of commands, and press Enter.

## Facts

- Type / at the beginning of a line or after any blank space
- Enter the command name to search, navigate with the arrow keys, press Enter
- Press Esc or the Space key to exit without invoking a command
- Fuzzy matching like the Command palette: type scf to find Save current file

## Try in five minutes

Enable Slash commands, then in a note type / on a new line, type scf and press Enter to run Save current file; type / again and press Esc to leave the menu without running anything.
