# Obsidian - Random note

Random note is a core plugin that opens a random note from the vault, to rediscover old notes and link to recently added ones.

## Facts

- Opens a random note within your vault
- Click Open random note (the dice icon) in the Ribbon
- Meant for rediscovering notes to add new insights or link to recently added notes

## Try in five minutes

Click Open random note in the ribbon five times; for each note that appears, add one `[[wikilink]]` to a related note or a tag before moving on.
