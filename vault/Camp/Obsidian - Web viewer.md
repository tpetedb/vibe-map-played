# Obsidian - Web viewer

Web viewer is a desktop core plugin that opens external links in Obsidian tabs, with a reader view, a save-to-vault action and ad blocking, for research without leaving the app.

## Facts

- External links open as a tab you can rearrange, split or move to a pop-out window; web page cards in canvas open as web viewer tabs
- Click the glasses icon for Reader view, a plain text version cleaned with Mozilla's Readability library
- Save a page to the vault from the more actions icon; set the location under Settings > Web viewer
- Ads are blocked by default; add rule lists such as Easylist
- Not a replacement for a browser: while Obsidian runs, third-party plugins have full access to cookies in Web viewer, so use a real browser for password-protected sites

## Try in five minutes

Enable Web viewer, click an external link in a note so it opens in a tab, switch to Reader view with the glasses icon, then use the more actions icon to save the page to your vault and open the resulting note.
