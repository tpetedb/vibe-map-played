# Obsidian - Page preview

Page preview is a core plugin that shows a popup preview of a note when you hover over an internal link, without navigating to it.

## Facts

- Hovering a link previews the file in File explorer, Search, Backlinks and more
- In Editing view, press Ctrl (Cmd on macOS) while hovering the cursor over the link
- An option under Core plugins > Page preview makes Ctrl/Cmd required while hovering
- Preview is on by default; toggling the plugin option turns the behaviour off

## Try in five minutes

Open a note with an internal link, hover the link while holding Ctrl (Cmd on macOS) to see the preview popup, then hover a result in Search without the key and compare.
